# Web Development Lab

This project contains multiple HTML practice files covering HTML, CSS, and JavaScript exercises.

## Files

- `html-css-lab.html` — HTML and CSS lab page
- `css-75-practical-lab.html` — CSS practical examples and selectors
- `javascript-practical-lab.html` — JavaScript practical exercises
- `javascript-complete-lab.html` — advanced JavaScript lab
- `web-development-lab.html` — landing page linking all labs

## How to use

Open `web-development-lab.html` in a browser to view the lab index and navigate to each page.

## Notes

These files are educational practice pages and can be edited or expanded further.
